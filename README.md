# Smart Bus Reservation System

A Python-based bus reservation system developed using Tkinter and SQLite. 
The application allows users to view available buses, reserve seats, enter passenger details, generate tickets, and manage bookings.

## Features

- View available buses and routes
- Select and reserve seats
- Enter passenger details
- Generate booking tickets
- View previous bookings
- Cancel bookings
- Admin dashboard
- SQLite database for storing booking information
- Simple graphical user interface using Tkinter

## Technologies Used

- Python
- Tkinter
- SQLite3

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python IDE.
4. Run:
